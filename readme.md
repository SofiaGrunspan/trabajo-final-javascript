# TaskFlow - Trabajo Final JavaScript

Proyecto realizado como trabajo final del **Módulo 2 - Introducción a JavaScript**.

## Descripción

TaskFlow es una aplicación web sencilla desarrollada para practicar los conceptos básicos de JavaScript y la manipulación del DOM.

La aplicación incluye dos funcionalidades principales:

- Lista de tareas.
- Calculadora básica.

### Lista de tareas

Permite:

- Agregar nuevas tareas.
- Marcar tareas como completadas.
- Eliminar tareas.

### Calculadora

Permite realizar las siguientes operaciones:

- Suma
- Resta
- Multiplicación
- División

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Conceptos de JavaScript utilizados

Durante el desarrollo se utilizaron conceptos básicos como:

- Variables
- Funciones
- Arrays
- Condicionales
- Eventos
- `addEventListener()`
- Manipulación del DOM
- `getElementById()`
- `createElement()`
- `appendChild()`
